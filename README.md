# OVERBID CAPITAL — Cursor build directive pack
Version 1.0 · 2026-11-03 · Design specification, not a finished application

Build a distinctive M&A and business-listing experience from these specifications. The approved direction is the ivory third-eye white rabbit in a broken acid-green triangle, obsidian architecture, precise modern type, and restrained esoteric geometry. This pack includes ten visual references, exact copy, design tokens, interaction contracts, asset prompts, and release gates.

## Install into a fresh project
1. Extract the ZIP. Copy **the contents of `overbid-build-pack/`** into your project root, including `AGENTS.md` and the hidden `.cursor/` folder. On Windows enable hidden items if needed.
2. If the project already contains instructions or configuration, merge deliberately; do not overwrite unrelated files. `Reference-Guidelines/` contains references only, not deployable full-page images.
3. Open the project root in Cursor. Start with `START-HERE.md`; paste `prompts/CURSOR-KICKOFF.md` into Agent.
4. Use the first milestone to scaffold the application and reproduce the static page. Approve the composition before animation or backend expansion.
5. Configure credentials in an ignored `.env.local` only when needed. `.env.example` contains names, not secrets.

## Scope decision
Default first delivery: a working **demo** of the seven-section site, optional intro, searchable sample marketplace, sample details, local saved opportunities, draft listing wizard, and validation of the introduction form. It must be visually labelled as demo/sample where relevant. No false submissions, fake verification, hidden paid generation, fabricated team, invented inventory or unsupported outcome claims.

Production persistence, accounts, identity checks, private documents, seller approval workflows, CRM delivery and real inventory are the next milestone with explicit service configuration. Implement contracts now, but never claim services are connected before proving it.

## Success
Screenshots align with the supplied design references; content is live HTML; navigation and demo flows work; mobile is intentionally composed; reduced-motion and keyboard access work; no secrets reach the client; all unresolved launch requirements are visible in the delivery report.

No directive can guarantee a flawless first pass. This pack defines an inspectable implementation and iteration process that makes quality measurable.
