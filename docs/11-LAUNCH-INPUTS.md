# 11 — Owner inputs before live launch

These do not block the labelled demo. They block corresponding production claims/features.

| Input | Why | Until supplied |
|---|---|---|
| Legal operator name,address,contact | accountability/disclosures | no invented identity |
| Actual service scope and jurisdictions | roles and applicable obligations | describe only demo platform |
| Real team profiles/credentials | trust section | honest prelaunch message |
| Listing/advisory fees and agreements | transparent engagement | no claims of free service or success fee |
| Approved privacy/terms/retention | collection and handling | draft pages,no live data collection |
| Lead delivery destination | durable submissions | demo validation only |
| Auth/database/storage choice | ownership and private access | local nonsensitive draft demo |
| Domain control/deployment target | canonical URLs and launch | local preview,no DNS changes |
| Accurate logo vector and font licenses | production branding | supplied raster marked source |
| KIE variant/account/budget | paid generation | dry-run only |
| Real seller authorization/listing data | public marketplace | labelled sample inventory |
| Buyer qualification policy | truthful access claims | no verified buyer badge |

Track decisions with owner,date and affected spec. No guessed licensing/regulated-status statements. No 'trusted by' logos without permission/evidence.
